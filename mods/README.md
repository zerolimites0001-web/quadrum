# Importação de mods

Esta pasta não é escaneada nem executada pelo jogo.

Use **Mods → Importar ZIP / Importar pasta / JS / arquivos** e selecione os arquivos
explicitamente. Exemplos distribuídos estão em [`../examples/mods/`](../examples/mods/).
Os arquivos selecionados são copiados para IndexedDB; o loader não recebe acesso
genérico às pastas do aparelho.

Guia completo: [`../MODDING.md`](../MODDING.md).
